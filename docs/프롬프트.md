# 오늘의 하늘 사이트 — 프롬프트 기록

## 프로젝트 목표

매일 날씨와 명언을 보여주는 사이트를 만든다. 날씨와 명언은 API를 사용하고, 사이트는 로컬에서 실행할 수 있어야 한다.

## 요구사항 및 변경 프롬프트

1. **사이트 생성**
   - 매일 날씨와 명언을 보여주는 웹사이트를 생성한다.
   - 날씨·명언 데이터는 API를 사용한다.
   - 사이트는 로컬에서 실행한다.
   - 구현에 앞서 계획을 먼저 제시한다.

2. **계획 승인 및 구현**
   - 제안된 구현 계획에 따라 진행한다.

3. **한글 명언**
   - 명언을 한글로 표시한다.

4. **로컬 실행 배치 파일**
   - 사이트를 쉽게 실행할 수 있도록 배치 파일을 생성한다.

5. **한국어 명언 API 지정**
   - `https://korean-advice-open-api.vercel.app/api/advice` API를 사용한다.

6. **명언 우선 화면 구성**
   - 명언을 날씨보다 위에 배치한다.
   - 명언이 화면에서 더 강조되도록 디자인한다.

7. **도시 검색 버튼**
   - 우측 하단의 검색 버튼을 돋보기 아이콘으로 바꾼다.

8. **날씨 세부 정보 배치**
   - 습도·바람·강수량을 현재 날씨 오른쪽으로 이동한다.
   - 모바일 화면에서도 날씨 오른쪽에 표시한다.

9. **프롬프트 문서화**
   - 지금까지의 프롬프트를 `docs/프롬프트.md`에 기록한다.
   - 같은 내용을 제공된 GitBook 페이지에도 마크다운으로 추가한다.

10. **무료 호스팅 선택**
    - 사이트를 무료 호스팅에 게시하기 위해 GitHub Pages를 선택한다.

## 구현 기준

- 화면과 안내 문구는 한국어로 제공한다.
- API 로딩 및 오류 상태를 사용자에게 알린다.
- 현재 위치 및 도시 검색으로 날씨 위치를 바꿀 수 있다.
- 명언은 날짜별로 저장해 같은 날에는 동일한 문장을 보여준다.
- 데스크톱과 모바일 화면 모두에서 레이아웃을 확인한다.
- Windows에서 배치 파일을 실행해 로컬 서버를 시작할 수 있도록 한다.
- GitHub Pages에서 정적 사이트를 배포하고, `main` 브랜치 업데이트 시 자동 배포한다.
